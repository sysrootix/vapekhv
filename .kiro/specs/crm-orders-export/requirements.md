# Requirements Document

## Introduction

Данная функция добавляет возможность экспорта отчета по заказам в формате Excel из CRM-панели. Администраторы и CRM-менеджеры смогут выбрать месяц и год для отчета, после чего система сгенерирует Excel-файл с детальной информацией о заказах за выбранный период, включая данные о стоимости доставки.

## Glossary

- **CRM System**: Система управления взаимоотношениями с клиентами, встроенная в приложение
- **Export Button**: Кнопка "Скачать отчет" в интерфейсе CRM
- **Period Selector**: Компонент выбора месяца и года для отчета
- **Excel Report**: Файл формата .xlsx с таблицей заказов
- **Order**: Заказ в системе со статусом DELIVERED
- **Delivery Cost**: Стоимость доставки, которую заплатил клиент
- **Admin Delivery Cost**: Фактическая стоимость доставки, которую заплатил администратор за такси

## Requirements

### Requirement 1

**User Story:** Как CRM-менеджер, я хочу экспортировать отчет по заказам за выбранный период, чтобы анализировать данные о продажах и доставке

#### Acceptance Criteria

1. WHEN CRM-менеджер открывает CRM-панель, THE CRM System SHALL отображать кнопку "Скачать отчет" в разделе Overview
2. WHEN CRM-менеджер нажимает на кнопку "Скачать отчет", THE CRM System SHALL отображать модальное окно с выбором периода
3. THE Period Selector SHALL предоставлять выбор месяца и года для отчета
4. WHEN CRM-менеджер выбирает период и подтверждает экспорт, THE CRM System SHALL генерировать Excel-файл с данными за выбранный период
5. THE CRM System SHALL автоматически загружать сгенерированный Excel Report в браузер пользователя

### Requirement 2

**User Story:** Как CRM-менеджер, я хочу видеть в отчете детальную информацию о каждом заказе, чтобы анализировать финансовые показатели

#### Acceptance Criteria

1. THE Excel Report SHALL содержать таблицу с заказами за выбранный период
2. THE Excel Report SHALL включать только заказы со статусом DELIVERED
3. THE Excel Report SHALL содержать столбец "Номер заказа" с уникальным номером Order
4. THE Excel Report SHALL содержать столбец "Сумма заказа" с общей суммой Order включая Delivery Cost
5. THE Excel Report SHALL содержать столбец "Человек заплатил за доставку" с суммой Delivery Cost, которую заплатил клиент

### Requirement 3

**User Story:** Как администратор, я хочу видеть в отчете фактическую стоимость доставки, чтобы контролировать расходы на логистику

#### Acceptance Criteria

1. THE Excel Report SHALL содержать столбец "Мы заплатили за такси" с суммой Admin Delivery Cost
2. WHEN Admin Delivery Cost не установлена для Order, THE CRM System SHALL отображать 0 или пустое значение в столбце
3. THE Excel Report SHALL форматировать все денежные значения с двумя десятичными знаками
4. THE Excel Report SHALL использовать русские названия для всех столбцов таблицы

### Requirement 4

**User Story:** Как CRM-менеджер, я хочу получать отчет быстро и без ошибок, чтобы эффективно работать с данными

#### Acceptance Criteria

1. WHEN выбранный период не содержит заказов, THE CRM System SHALL генерировать пустой Excel Report с заголовками столбцов
2. WHEN происходит ошибка при генерации отчета, THE CRM System SHALL отображать понятное сообщение об ошибке пользователю
3. THE CRM System SHALL генерировать Excel Report в течение 10 секунд для периода до 1000 заказов
4. THE Excel Report SHALL иметь имя файла в формате "orders_report_YYYY_MM.xlsx" где YYYY - год, MM - месяц
5. THE CRM System SHALL использовать библиотеку для генерации Excel-файлов на backend
