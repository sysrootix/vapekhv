# 🚀 Инструкция по деплою системы оплаты

## 📋 Что было добавлено

### Backend
1. **Новые статусы заказов**:
   - `PENDING_PAYMENT` - ожидает оплаты (1 час)
   - `PAYMENT_EXPIRED` - время оплаты истекло
   - Обновлены существующие статусы

2. **Новые поля в Order**:
   - `receiptImageUrl` - URL загруженного чека
   - `paymentExpiresAt` - время истечения оплаты
   - `paidAt` - время оплаты

3. **Новые API эндпоинты**:
   - `POST /api/orders/:id/upload-receipt` - загрузка чека
   - `POST /api/orders/:id/confirm-payment` - подтверждение оплаты админом

4. **Новые сервисы**:
   - `payment-notification.service.ts` - отправка уведомлений в Telegram группу админов
   - Обновлен `scheduler.service.ts` - автоотмена неоплаченных заказов через 1 час

5. **Файл-апло ад**:
   - Настроен `multer` для загрузки изображений чеков
   - Директория: `/uploads/receipts/`

### Frontend
1. **Новая страница PaymentPage**:
   - Отображение реквизитов для оплаты
   - Таймер обратного отсчета (1 час)
   - Загрузка чека с превью
   - Автоматическое обновление статуса

2. **Обновленный flow**:
   - Checkout → Payment → Orders
   - После создания заказа редирект на страницу оплаты

## 🔍 Troubleshooting

### Проблема: Миграция не применяется
```bash
# Сбросить shadow database
export PRISMA_MIGRATE_SKIP_SHADOW_DATABASE_CHECK=1
npx prisma migrate deploy
```

### Проблема: Уведомления не приходят в Telegram
```bash
# Проверить переменные окружения
cat backend/.env | grep TELEGRAM

# Проверить логи
pm2 logs vapekhv-backend | grep -i telegram

# Проверить что бот запущен
pm2 logs vapekhv-backend | grep "Payment notification bot"
```

### Проблема: Чеки не загружаются
```bash
# Проверить права на директорию
ls -la backend/uploads/receipts

# Проверить что multer установлен
cd backend && npm list multer

# Если нет - установить
npm install multer @types/multer
```

### Проблема: Frontend не обновился
```bash
# Очистить кеш браузера или
# Проверить что файлы скопировались
ls -la /var/www/vapekhv/

# Пересобрать и скопировать заново
cd /home/user/shop
npm run build:frontend
sudo cp -r frontend/dist/* /var/www/vapekhv/
sudo systemctl reload nginx
```

## 🎯 Тестирование полного flow

1. **Создание заказа**:
   - Добавить товар в корзину
   - Заполнить данные доставки
   - Нажать "Подтвердить заказ"
   - ✅ Должен перенаправить на `/payment/:orderId`

2. **Страница оплаты**:
   - ✅ Должен показаться таймер обратного отсчета (59:59)
   - ✅ Реквизиты карты видны
   - ✅ Кнопка копирования номера карты работает

3. **Загрузка чека**:
   - Выбрать изображение
   - ✅ Показывается превью
   - Нажать "Отправить чек"
   - ✅ Уведомление "Чек отправлен!"
   - ✅ Статус меняется на "Ожидает подтверждения"

4. **Уведомление админам**:
   - ✅ В Telegram группе админов появилось сообщение
   - ✅ Фото чека прикреплено
   - ✅ Кнопки "Одобрить" и "Отменить" есть

5. **Одобрение админом**:
   - Админ нажимает "✅ Одобрить"
   - ✅ Статус заказа меняется на "CONFIRMED"
   - ✅ Бонусы списаны/начислены
   - ✅ Остатки товаров уменьшены
   - ✅ Кнопки в сообщении исчезли

6. **Отмена по истечении времени**:
   - Создать заказ и не оплачивать 1 час
   - ✅ Через час статус автоматически меняется на "PAYMENT_EXPIRED"
