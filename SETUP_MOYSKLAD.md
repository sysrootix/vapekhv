# Быстрая настройка интеграции с МойСклад

## Шаг 1: Получить токен МойСклад

1. Войдите в МойСклад: https://online.moysklad.ru
2. Перейдите: **Настройки → Пользователи и права → Сотрудники**
3. Выберите пользователя или создайте нового
4. В разделе **API** нажмите **Сгенерировать токен**
5. Скопируйте токен (он выглядит как длинная строка)

## Шаг 2: Узнать свой Chat ID в Telegram

Есть несколько способов:

### Способ 1: Через бота @userinfobot
1. Найдите бота @userinfobot в Telegram
2. Напишите ему `/start`
3. Скопируйте ваш **Id** (это число вида `123456789`)

### Способ 2: Через ваш бот
1. Напишите `/start` вашему боту VapeKHV
2. Посмотрите логи сервера: `pm2 logs vapekhv-backend`
3. Найдите строку с вашим ID: `Пользователь ... (ID: 123456789)`

## Шаг 3: Настроить переменные окружения

На сервере откройте файл `.env`:

```bash
cd ~/shop/backend
nano .env
```

Добавьте/обновите следующие строки:

```env
# МойСклад токен
MOYSKLAD_TOKEN=ваш_токен_из_шага_1

# ID админов через запятую (для команды /sync)
ADMIN_CHAT_IDS=123456789,987654321
```

Сохраните файл: `Ctrl+O`, `Enter`, `Ctrl+X`

## Шаг 4: Очистить тестовые данные

Подключитесь к PostgreSQL:

```bash
psql -U postgres -d vapekhv_db
```

Выполните очистку:

```sql
-- Удаление всех тестовых данных
DELETE FROM "order_items";
DELETE FROM "orders";
DELETE FROM "cart_items";
DELETE FROM "product_characteristics";
DELETE FROM "product_variants";
DELETE FROM "products";
DELETE FROM "categories";
```

Выход из PostgreSQL: `\q`

## Шаг 5: Применить миграции БД

```bash
cd ~/shop/backend
npx prisma migrate dev --name add_moysklad_fields
npx prisma generate
```

## Шаг 6: Собрать и перезапустить проект

```bash
cd ~/shop
npm install  # Установить новые зависимости (node-cron)
npm run build
pm2 restart vapekhv-backend
```

## Шаг 7: Проверить работу

### Проверить логи запуска:

```bash
pm2 logs vapekhv-backend --lines 50
```

Вы должны увидеть:

```
✅ МойСклад конфигурация валидна
📅 Планировщик синхронизации запущен (каждые 30 минут)
🔄 Запуск первоначальной синхронизации с МойСклад...
```

### Запустить синхронизацию вручную:

В Telegram напишите вашему боту:

```
/sync
```

Бот ответит:

```
🔄 Синхронизация с МойСклад

Запускаю синхронизацию каталога...
Это может занять несколько минут.
```

После завершения:

```
✅ Синхронизация завершена!

⏱️ Время выполнения: 12.34с
📦 Каталог товаров обновлен

Запущено: YourName
```

## Что синхронизируется?

- ✅ **Категории** - все товарные группы из МойСклад
- ✅ **Товары** - название, описание, артикул, цена
- ✅ **Остатки** - количество доступных товаров
- ✅ **Изображения** - скачиваются и хранятся на сервере
- ✅ **Варианты** - модификации товаров с характеристиками
- ✅ **Цены** - актуальные цены из прайс-листа

## Автоматическая синхронизация

После настройки синхронизация будет происходить **автоматически**:

- 🔄 При запуске сервера
- ⏰ Каждые 30 минут (по расписанию)
- 🔧 По команде `/sync` от админа

## Настройка интервала синхронизации

Чтобы изменить интервал (по умолчанию 30 минут):

```bash
nano ~/shop/backend/src/config/moysklad.ts
```

Измените:

```typescript
syncIntervalMinutes: 30, // Изменить на нужное значение
```

## Troubleshooting

### Синхронизация не запускается

```bash
# Проверить логи
pm2 logs vapekhv-backend --err

# Проверить переменные окружения
pm2 env 0 | grep MOYSKLAD
```

### Ошибка авторизации МойСклад

Проверьте токен:
1. Убедитесь, что токен не истек
2. Проверьте, что токен скопирован полностью
3. Регенерируйте токен в МойСклад при необходимости

### Изображения не скачиваются

```bash
# Проверить права на директорию
ls -la ~/shop/backend/uploads/
chmod -R 755 ~/shop/backend/uploads/
```

### Команда /sync не работает

1. Проверьте, что ваш Chat ID добавлен в `ADMIN_CHAT_IDS`
2. Перезапустите бот: `pm2 restart vapekhv-backend`
3. Проверьте логи: `pm2 logs vapekhv-backend`
