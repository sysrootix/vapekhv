# ✅ Модальное окно подтверждения возраста 18+

## 📋 Описание

Добавлено модальное окно подтверждения возраста, которое показывается пользователю при первом входе в Telegram Web App. Окно требует подтверждения, что пользователю исполнилось 18 лет, перед использованием приложения.

## 🎯 Особенности

- ✅ Показывается только при первом входе (сохраняется в localStorage)
- ✅ Адаптивный дизайн для всех экранов и устройств
- ✅ Поддержка safe-area для устройств с вырезом (iPhone X и новее)
- ✅ Анимации и плавные переходы
- ✅ Блокировка скролла при открытом модальном окне
- ✅ Стиль в соответствии с Telegram Web App дизайном
- ✅ Нельзя закрыть без подтверждения (обязательное согласие)

## 📱 Адаптивность

Модальное окно оптимизировано для:
- Мобильных устройств (iPhone, Android)
- Планшетов
- Десктопов
- Устройств с вырезом (safe-area support)
- Разных размеров экранов (от 320px до больших экранов)

## 🔧 Технические детали

### Компонент
`frontend/src/components/AgeVerificationModal.tsx`

### Функции экспорта
- `checkAgeVerification()` - проверяет, было ли подтверждено ранее
- `setAgeVerificationConfirmed()` - сохраняет подтверждение в localStorage

### Ключ хранения
`age-verification-confirmed` в localStorage

## 📝 Текст модального окна

**Заголовок:** "18+"

**Основной текст:**
> Продолжая пользоваться приложением, вы подтверждаете, что вам **исполнилось 18 лет**.

**Важное предупреждение:**
> Продукция, представленная в нашем магазине, предназначена только для лиц, достигших совершеннолетия.
> 
> Использование вейп-продукции несовершеннолетними запрещено законодательством Российской Федерации.

**Кнопки:**
- "Мне есть 18 лет" (основная, подтверждающая)
- "Мне нет 18 лет" (закрывает приложение)

## 🚀 Использование

Модальное окно автоматически показывается при первом запуске приложения. После подтверждения оно больше не будет появляться для этого пользователя.

### Ручной сброс (для тестирования)

Чтобы сбросить подтверждение и увидеть модальное окно снова:

```javascript
localStorage.removeItem('age-verification-confirmed');
// Перезагрузите страницу
```

## ✅ Интеграция

Модальное окно интегрировано в `App.tsx` и показывается:
1. После инициализации Telegram Web App
2. До показа основного контента приложения
3. Только если пользователь еще не подтвердил возраст

## 🎨 Дизайн

- Использует Telegram Web App цветовую схему (`tg-*` классы)
- Градиентный фон для заголовка
- Иконка предупреждения с анимацией
- Плавные анимации появления/исчезновения
- Тени и эффекты для глубины

## 📦 Зависимости

- `framer-motion` - для анимаций
- `lucide-react` - для иконок (AlertTriangle, Shield)

## 🔒 Безопасность

- Подтверждение сохраняется в localStorage браузера
- Нельзя закрыть модальное окно без выбора одного из вариантов
- При отказе приложение закрывается через Telegram Web App API
